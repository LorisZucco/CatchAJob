💼 CatchAJob

O CatchAJob é um projeto web desenvolvido com o objetivo de simular uma plataforma de busca de empregos voltada para a área de tecnologia.

A aplicação permite que o candidato informe seus dados, experiências, habilidades e preferências profissionais. A partir dessas informações, o sistema analisa o perfil e realiza uma verificação de compatibilidade com as vagas disponíveis, apresentando ao usuário as oportunidades mais adequadas ao seu perfil.

🎯 Objetivo do projeto

O projeto foi desenvolvido com foco na aplicação prática dos conhecimentos adquiridos em HTML, CSS e JavaScript, trabalhando conceitos como manipulação do DOM, módulos JavaScript, eventos, formulários, armazenamento local e organização da lógica da aplicação.

Atualmente, a aplicação simula apenas a experiência do candidato, sem autenticação ou integração com um back-end.

⚙️ Funcionalidades

Cadastro das informações do candidato;

Armazenamento de dados utilizando localStorage;

Persistência das informações no navegador;

Exibição das vagas disponíveis;

Análise de compatibilidade entre candidato e vagas;

Organização das vagas de acordo com o perfil informado;

Interface desenvolvida com HTML, CSS e JavaScript.

🛠️ Tecnologias utilizadas

HTML5 — estrutura e semântica da aplicação;

CSS3 — estilização e organização visual;

JavaScript — lógica e interatividade;

ES Modules — organização e separação do código JavaScript;

LocalStorage — persistência dos dados no navegador.

🚀 Como executar

Clone ou faça o download deste repositório.

Abra a pasta do projeto no Visual Studio Code.

Execute o projeto utilizando uma extensão como Live Server ou outro servidor local.

Preencha o formulário do candidato.

O sistema analisará as informações e exibirá as vagas disponíveis de acordo com o perfil informado.
